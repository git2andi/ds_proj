# Decide how to split the shared garden plot this season

Six participants need to decide how to divide a shared garden plot of 600 square feet for this growing season. The plot can be split evenly, by preference, by crop type, or by effort contributed.

## Options

- A) Equal Six-Way Split — total area sqft: 600; plots: 6; plot size sqft: 100; division method: equal_area (+ Each participant receives an equal area of 100 square feet; − No consideration for individual crop preferences or effort levels)
- B) Preference-Based Allocation — total area sqft: 600; plots: 6; division method: based_on_individual_preferences; max plot size sqft: 150; min plot size sqft: 50 (+ Participants receive plot sizes aligned with their crop preferences; − Plot sizes vary, which may cause disagreements about fairness)
- C) Crop-Type Grouping — total area sqft: 600; division method: grouped_by_crop_type; crop groups: 3; plots per group: 2 (+ Plots are organized by crop type, facilitating shared care and resources; − Participants growing different crops must share plots, reducing individual control)
