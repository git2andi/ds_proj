# Choose the game engine for the student game project

A group of seven students must select a game engine for their collaborative project. The engine should support 2D and 3D development, have accessible learning resources, and allow deployment on multiple platforms.

## Options

- A) Unity Game Engine — supported platforms: Windows, macOS, Linux, iOS, Android, Web; graphics capability: 2D and 3D; scripting language: C#; learning resources: Extensive official tutorials and community forums (+ Widely used with a large community and many learning materials; − Can have a steep learning curve for beginners)
- B) Unreal Engine — supported platforms: Windows, macOS, Linux, iOS, Android, Consoles; graphics capability: High-fidelity 3D and VR support; scripting language: C++ and Blueprints visual scripting; learning resources: Comprehensive documentation and video tutorials (+ Strong for high-quality 3D graphics and visual scripting options; − More complex interface and resource-intensive for smaller projects)
- C) Godot Engine — supported platforms: Windows, macOS, Linux, iOS, Android, Web; graphics capability: 2D and 3D; scripting language: GDScript, C#, VisualScript; learning resources: Growing community with open-source tutorials (+ Open-source with a lightweight interface and flexible scripting; − Smaller community and fewer third-party assets compared to others)
- D) GameMaker Studio 2 — supported platforms: Windows, macOS, iOS, Android, Web; graphics capability: Primarily 2D; scripting language: GML (GameMaker Language); learning resources: Beginner-friendly tutorials and active forums (+ Simplified 2D development with an easy-to-learn scripting language; − Limited 3D capabilities and fewer export options for consoles)
