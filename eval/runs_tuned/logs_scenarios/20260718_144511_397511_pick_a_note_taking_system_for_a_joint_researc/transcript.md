# Pick a note-taking system for a joint research project

Two researchers need to select a note-taking system for their joint project. The system must support text and image notes, allow easy sharing, and work on both Windows and mobile devices.

## Options

- A) Microsoft OneNote — platforms: Windows, iOS, Android, Web; note types: text, images, audio; sharing: real-time collaboration; cost: free with Microsoft account (+ Supports rich media notes and seamless syncing across devices; − Interface can be complex for new users)
- B) Evernote — platforms: Windows, iOS, Android, Web; note types: text, images, PDFs; sharing: shared notebooks with permissions; cost: free tier with limited uploads (+ Organizes notes with tags and powerful search features; − Free version limits monthly upload size)
- C) Google Keep — platforms: Web, iOS, Android; note types: text, images, voice notes; sharing: real-time collaboration; cost: free (+ Simple interface with quick note creation and reminders; − Limited organization features compared to other apps)
- D) Notion — platforms: Windows, iOS, Android, Web; note types: text, images, databases; sharing: real-time collaboration with permissions; cost: free personal plan with collaboration (+ Highly customizable workspace combining notes and project management; − Steeper learning curve for advanced features)
