# Decide on the visual style for a mobile puzzle game

The team must select a visual style for a mobile puzzle game targeting casual players aged 18-35. The style should support clear gameplay visibility and be feasible to implement within a 3-month development cycle.

## Options

- A) Minimalist Flat Design — color palette: limited, pastel tones; complexity: low; art style: 2D vector graphics; development time: short (+ Ensures clear gameplay elements and fast rendering on all devices; − May appear less visually engaging to players seeking rich graphics)
- B) Hand-drawn Cartoon Style — color palette: vibrant, varied; complexity: medium; art style: 2D hand-illustrated; development time: medium (+ Creates a friendly and approachable atmosphere that appeals to casual players; − Requires more art resources and slightly longer production time)
- C) 3D Low-Poly Style — color palette: bright, solid colors; complexity: medium-high; art style: 3D low-polygon models; development time: medium (+ Adds depth and visual interest while maintaining performance on mobile devices; − May complicate UI clarity and increase development complexity)
- D) Retro Pixel Art — color palette: limited, high contrast; complexity: low-medium; art style: pixel-based 2D; development time: short-medium (+ Appeals to nostalgia and supports simple, recognizable gameplay visuals; − Might not attract players expecting modern graphical styles)
