# Decide on the exhibition layout for the student art show

The student art show requires a layout that accommodates 4 artists and their works in a single exhibition space. The layout must allow clear visitor flow, adequate lighting, and space for both 2D and 3D artworks.

## Options

- A) Linear Gallery Layout — artist sections: 4; visitor flow: one-way; lighting: overhead track; space type: narrow corridor (+ Facilitates a guided, sequential viewing experience; − Limited space may restrict display size for larger 3D pieces)
- B) Central Island Layout — artist sections: 4; visitor flow: circular; lighting: spotlights on islands; space type: open floor (+ Allows visitors to move freely around each artist’s work; − May create congestion in the center during peak times)
- C) Zoned Corner Layout — artist sections: 4; visitor flow: multi-directional; lighting: adjustable wall-mounted; space type: corner alcoves (+ Provides distinct, intimate spaces for each artist; − Visitors might miss some sections if not clearly signposted)
- D) Mixed Media Cluster Layout — artist sections: 4; visitor flow: free-form; lighting: combination natural and artificial; space type: clustered pods (+ Supports varied artwork types with flexible display options; − Less structured flow can cause uneven visitor distribution)
