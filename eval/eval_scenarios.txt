# eval_scenarios.txt
# 50 fixed dialogue topics for evaluation runs.
# One topic per line. Lines starting with # are ignored.
# Covers everyday decisions, professional settings, and social contexts
# with varying levels of natural conflict to stress-test all dialogue phases.

# --- Everyday personal decisions ---
Where should we go for dinner tonight?
Which streaming service should we keep — we can only afford one?
Should we get a dog or a cat?
What should we do for the long weekend?
Which gym should we join?
Should we redecorate the living room or the bedroom first?
Which secondhand car should we buy?
Where should we go on our summer holiday?
Should we move to a bigger flat or stay and save money?
Which phone upgrade is worth it?

# --- Group / social decisions ---
Where should we hold the friend group's annual reunion?
What theme should the office Christmas party have?
Which charity should we donate our fundraising money to?
Should the book club switch to a monthly or biweekly meeting?
Which board game should we buy for game nights?
Should we split the restaurant bill evenly or by what we ordered?
Where should the running club hold its end-of-season celebration?
Which team name should we use for the pub quiz league?
Should we go camping or rent a cabin for the weekend trip?
Which city should we visit for the bachelor/bachelorette trip?

# --- Work and professional decisions ---
Which project management tool should the team adopt?
Should the company switch to fully remote, hybrid, or full office?
Which conference should we send our junior staff to this year?
Should we hire a contractor or train an internal person for the new role?
Which vendor should we use for the new CRM system?
Should the team hold its weekly standup in the morning or afternoon?
Which open-source library should we use for the authentication module?
Should we prioritise the mobile app or the desktop app rewrite?
Which design agency should we hire for the brand refresh?
Should the team adopt a four-day work week pilot?

# --- Community and civic decisions ---
Which park should the neighbourhood association upgrade first?
Should the community centre add a café or a coworking space?
Which local business should the community award support this year?
Should the school fundraiser be a raffle, a bake sale, or a sponsored run?
Which traffic-calming measure should the council approve for the high street?
Should the library extend its opening hours or add more digital resources?
Which of the proposed murals should be painted on the underpass wall?
Should the sports club buy new kit or upgrade the changing rooms?
Which route should the new cycling lane follow through the town centre?
Should the village fete move to a larger venue or keep its traditional location?

# --- Housing and living arrangements ---
Which neighbourhood should we move to?
Should we renovate the kitchen now or wait until we have more savings?
Should we use a letting agent or manage the rental property ourselves?
Which coworking space should the freelancer group share?
Which internet provider should the shared house switch to?
Which storage solution is best for the overcrowded home office?
Should we buy or rent the next place we live in?
Which home security system should we install?
Should the flatmates get a cleaner or divide the cleaning rota themselves?
Which energy supplier offers the best deal for the household?
