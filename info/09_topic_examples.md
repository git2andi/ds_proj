# Topic examples

Suitable topics present a bounded group decision with several plausible public options:

- choose a research-data storage setup;
- select a community fundraiser format;
- choose an apartment energy-saving upgrade;
- select a documentary for a discussion club;
- choose a prototype shipping method;
- select a weekend activity, hiking route, presentation format, meeting format, or shared device.

Avoid topics requiring unrestricted web knowledge, hidden factual research, or safety-critical professional decisions. The simulator assumes that objective option facts are fully represented by the public board.
