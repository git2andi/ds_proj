KI01 resolved 2026-06-30.

The prompt now requires a named option plus explicit first-person choice or acceptance wording. Validation normalizes typographic apostrophes and treats clear vote/accept wording as equivalent visible support on either routed decision act. Vague preference statements remain non-binding, and uncertain or conditional vote/accept language is neutral in both validation and state parsing.

Repairs cannot replace a state-valid turn with a new state-blocking defect; the original provider-written line is retained if a rewrite regresses semantic validity.

GPT validation covered n=2, n=3, n=5, and n=7 across five runs: 25 decision turns, one unclear-commitment repair trigger, zero final unclear commitments, and zero blocked decision turns. The final post-tightening n=3 run had no unclear-commitment trigger.
